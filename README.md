# 校园网有线登录工具 v2.3.1

一个用于自动登录校园网有线网络的 Python 应用程序，支持 Windows 系统。该工具可以自动检测网络状态、登录认证，并提供系统托盘图标方便管理。

## 功能特性

- **自动登录认证**：自动连接校园网有线网络并进行认证
- **系统托盘管理**：提供系统托盘图标，方便查看状态和管理
- **开机自启**：支持设置开机自启，确保网络连接持续可用
- **网络状态监控**：定时检查网络连接状态，自动重连
- **配置持久化**：保存用户名、密码等登录信息
- **日志记录**：详细的日志记录，便于问题排查
- **密码加密**：使用加密算法安全存储密码
- **多服务器支持**：支持主服务器和备用服务器
- **单实例运行**：防止多个实例同时运行

## 系统要求

- Windows 操作系统
- Python 3.7 或更高版本
- 管理员权限（用于网络接口操作）

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 直接运行

```bash
python "Wired-network.py"
```

### 打包为可执行文件

```bash
# 首先安装 PyInstaller
pip install pyinstaller

# 使用预配置的spec文件打包（推荐）
pyinstaller portable_exe_optimized.spec

# 或者直接打包
pyinstaller --onefile --windowed --icon=icon.ico Wired-network.py
```

打包后的可执行文件将在 `dist/` 目录中生成。

## 配置文件

程序会自动创建 `login_config.ini` 配置文件，包含：
- 用户名
- 密码（加密存储）
- 自动登录设置
- 其他网络配置

您也可以参考 `config_template.ini` 文件了解所有可用的配置选项。

## 技术栈

- Python 3
- PyQt5（GUI 和系统托盘）
- pystray（系统托盘图标）
- Pillow（图像处理）
- requests（网络请求）
- pywin32（Windows 系统功能）
- cryptography（密码加密）

## 文件说明

- `Wired-network.py` - 主程序文件
- `requirements.txt` - 项目依赖
- `login_config.ini` - 登录配置文件
- `dist/` - 打包后的可执行文件目录
- `logs/` - 日志文件目录

## 故障排除

1. **无法连接网络**：检查网线是否连接正常
2. **认证失败**：确认用户名和密码正确
3. **权限问题**：确保以管理员权限运行程序
